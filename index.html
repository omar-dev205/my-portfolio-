About Me

Practical AI automation, built end to end

I'm a Python developer focused on AI automation. I build chatbots, agents and workflows that take a task a person does by hand — answering customers, logging invoices, qualifying leads, publishing content — and run it automatically with an LLM in the loop.

My work combines Python, n8n and Make.com with LLM APIs like Gemini and Groq, connected to tools such as Google Sheets and Telegram. My most complete project is MAYA, a sales agent in the omni-sales-ai-agent repository.

I'm open to freelance projects and remote roles. Every project below links to its source code, so you can judge the work yourself.
